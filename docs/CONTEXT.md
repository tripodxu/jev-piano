# CONTEXT.md — 领域模型与术语表

> 本项目统一语言。**写代码、写文档、写 prompt 都用这里的词**，不要自造同义词。
> agent 按需查阅：改和声/乐理时读 §1–2，改决策流时读 §3，改界面时读 §4，改部署时读 §5。
>
> **维护约定**：引入新术语时在此登记。**判据是「这个词在别处会不会被误读」**——
> 内部实现细节（临时变量、纯局部的函数名）不登记；跨文件/跨会话会被反复引用的词必须登记。
> 2026-10-01 做了一次全量回填：轮次 20–49 新增的词（决策预算、问答、速度弧线、归零层等）此前均未登记。

## 1. 产品域（这个项目是什么）

| 术语 | 定义 |
|---|---|
| **jev-piano** | 本项目。一句话灵感 → 现场编曲 → 现场弹奏的即兴钢琴 |
| **Jev** | TypeSafe 的"系统一"结构化决策模型。输入文本 state + 一组类型化问题，输出每个问题的选择/评分。延迟 70–500ms，输入计费、输出免费 |
| **每小节一次请求** | 核心节奏：一个小节 = 一次 Jev 请求 = 八问并行。成本 ~1860 input tokens ≈ $0.000078/小节 |
| **决策透明** | 每小节的选择、概率/置信度、延迟、tokens、费用全部展示在 UI——每个音符可溯源 |
| **两个界面** | 「实时即兴」（边决策边演奏，不可预知）与「工作室」（批量生成→钢琴卷帘编辑→导出） |
| **lookahead 调度** | 提前 2 小节做决策，把 0.4–2s 的 API 延迟藏在小节时长（0.86–4s）里，演奏不断流 |
| **生产地址** | <https://jevpiano.logicc.top/>（Cloudflare Workers + 自定义域）。裸域 `*.workers.dev` 在部分网络被 DNS 投毒，核验脚本默认打自定义域 |

## 2. 乐理域（候选集的词汇）

| 术语 | 定义 |
|---|---|
| **候选集（candidate set）** | 代码按乐理+风格生成的有限选项集合，Jev 只能在其中选择。**非法和声不可表示** |
| **候选全集** | = **风格进行池 ∪ 调式全色板**。只有进行池时 romantic 小调仅 6 个根音，并集后词汇随调式自动增长 |
| **调式全色板（modePalette）** | 某调式的全部调内和弦，带调式性质（小调 iiø、大调 viiø、dorian bVII）。**词汇量的来源** |
| **罗马数字和弦** | `I/ii/V7/bVI/bVII/V7sus4/im9` 等，`parseRoman` 解析为 `{rootPc, shape}` |
| **替换候选（subs）** | 副属（`V7/x`）、借用 `iv`、`7sus4` 悬挂、导七进入候选的**高权重替换项**。轮次 14 已证伪「给池内候选加权」——**要撬动词汇必须走替换候选这一层** |
| **Plan（乐章计划）** | 全局配置：title/styleId/mode/keyPc/bpm/arc/swing/density/brightness/mood/notes/seed。所有模块只读 |
| **arc（弧线）** | 情绪曲线：flat/rise/arch/fall，映射到 intensity 曲线 |
| **sections / 曲式** | `[{id, arc, level, swing, bars, start}]`，经典 **A 陈述 → B 对比 → A' 再现 → Coda 收束**。长度恒为乐句长整数倍，故段落边界与乐句边界天然对齐 |
| **段落语义** | 段落边界不只是响度刻度：段落首**从主和弦重新立足**且**重述主题**（`developCandidates` 段落首 `repeat += 1.6` / `new *= 0.3`）；实测段落首承袭率 16.7%→45.8% |
| **phrase（乐句）** | 8 小节一句；`is_phrase_end` 小节终止式加权（V/I） |
| **问答（period）** | 每乐句**前四小节半终止「发问」**（属功能悬挂）、**后四小节全终止「回答」**（收束回家）。实测问句尾属功能 14.6%→27.1% |
| **phraseRole** | 归因字段：`'question'`（问句尾）/ `'answer'`（答句尾）/ `null`。界面在功能轨第三槽显示「问/答」（文字+形状双通道） |
| **动机（motif）** | 第 2 小节固化的旋律素材（`midis` 音高序列 + `onsets` 节奏网格 + `intervals` 音程轮廓）。承袭的原料 |
| **发展手法** | 第 8 问（`develop`）：`repeat` 承袭 / `sequence` 模进 / `inversion` 倒影 / `ornament` 装饰 / `new` 新句。**素材来源有分工**：`repeat` 用**动机**，其余用**上一小节** |
| **和声功能** | 第 1 问（`function`）：先声明下一小节往哪类功能走（T/S/D/Tp），和弦在第 2 问仍在候选集内选；**不做硬过滤**——用途是语义语境、非法答复回落到所声明功能族、以及给 UI 比罗马数字更有意义的可读维度 |
| **功能转移矩阵** | `T→{S,D}`、`S→{D,Tp}`、`D→{T}`、`Tp→{D,T}`；乐句尾强制 `D→T` |
| **声部进行加权** | `smoothness = 共音数 − 0.25 × 五度圈环形距离`。共音越多、五度圈越近，候选权重越高。`W_SMOOTH` 锁 0.5 |
| **指纹护栏** | onset+绝对音高指纹，**双层记忆**：`lastSigs`（最近 2 小节，**硬**层，相邻字面重复绝不允许）+ `allSigs`（全曲含跨遍，**软**层，远距离复读尽量避开）。撞车时迭代变形（移调/加经过音/倒影/节奏压缩/音高扫掠）直到避开**全部**已存指纹 |
| **硬化/软层语义** | 硬层违反 = 失败（测试红）；软层违反 = 尽力而为，**必须如实记账**（`farRepeat`/`lhFarRepeat` → 界面「复读」标记）。**「尽力而为」的系统必须有「如实记账」的出口，否则退化成假承诺** |
| **根音疲劳断路器** | 根音疲劳值随使用累计、×0.93 衰减，超 2.0 即从候选集剔除；三和弦循环最多 6 小节必被打断 |
| **循环锁死断路器** | 最近 6 小节根音只剩 ≤3 个不同值即判定"正在绕圈"，把**循环成员**剔出候选。与疲劳互补：疲劳是"用得太多"（攒得慢），锁死是"结构上正在绕圈"（当小节生效） |
| **候选集强制** | 模型答案不在候选集内（含用标签作答、报被排除和弦）一律拒绝，回落最高权重候选 |
| **LH 织体** | 左手伴奏型 **11 种**：block/ballad/alberti/arp/broken/waltz/shell/stride/walk/octave/pad；每种带逐小节变体（重击/空拍/方向翻转/色彩换位/经过音/音区抬升） |
| **节奏型 / 走向** | RH 的 onset 模式（r0 稀疏/r1 中/r2 密/motif）与音高轮廓（stay/rise/fall/arch/wave） |
| **强度连续化** | Jev 的强度问按 API 契约只答 0–3 整数。把整数解释为**相对计划弧线的偏移**（`INTENSITY_DEV=0.5`，模型保留一半发言权），再施加每小节 1 档**速率限制**（`INTENSITY_SLEW=1.0`）。跳≥2 档 26.9%→0% |
| **呼吸（breathe）** | `noul` 问。**是时值指令（延后进入），不是否决指令（不许用素材）**——四条变形手法在有呼吸时也必须用上素材；兜底走 `fresh()` 后**归因强制改为 `new`**。延后量取自动机自己的最小节奏间距 |
| **速度弧线 / tempoMultAt** | `tempoMultAt(plan, bar)` 每小节一个速度乘数，小节内恒定。最后一段线性 rit.（1.0→**0.8**），arch/rise 段轻微推进（`TEMPO_PUSH=1.04`）。常量 `TEMPO_RIT_FLOOR=0.8`。**不改任何音符**，纯渲染层 |
| **曲终手势** | 每遍**末小节**旋律末音收束到**调性主三和弦**（比乐句尾"锚当前和弦"更强的收束），左手主音踏板贯穿整小节。时间维度的收束由 rit. 承担，**不做双重强调** |
| **fixture** | 无 API 时的确定性种子决策器：**与真实 Jev 同候选集、同权重**，同构兜底，UI 标注"离线随机" |

## 3. 技术域（代码的词汇）

| 术语 | 定义 |
|---|---|
| **NoteEvent** | `{midi, startBeats, durBeats, vel, hand:'R'\|'L'}`——渲染产物，时间以拍计 |
| **BarResult** | `Composer.nextBar()` 的输出：index/loop/label/chord/notes/intensity/decision |
| **decision** | BarResult 里的决策元信息（见下条逐字段） |
| **decision 的计费/健康字段** | `provider`（渠道名）· `fixture`（是否离线兜底）· `ms`（决策耗时）· `inputTokens` · `usd` · `confidence` |
| **decision 的归因字段** | `loopLocked`（断路器切刀）· `rejected`（答案越界被驳回）· `farRepeat`/`lhFarRepeat`（软层复读）· `deadlineMiss`（决策超预算）· `fn`（模型声明的功能）· `chordFn`（和弦实际所属功能）· `phraseRole` |
| **八问** | 按源码顺序：`function` / `chord` / `lh` / `rhythm` / `contour` / `intensity` / `breathe` / `develop`，一次请求并行。**顺序即语义依赖序**（function 先于 chord 叙事） |
| **四渠道** | `fixture`（默认零 key）/ `typesafe` 直连 / `openrouter` 直连 / `proxy`（同源 Worker） |
| **state（发给模型的文本）** | `piece`（风格/情绪/目标/弧线/调/拍/速）· `position`（小节/乐句内位置/是否乐句尾/进度/段落/是否段首段末）· `form`（**整条曲式** `A:flat@1.2 B:rise@1.9 …`）· `harmony`（当前和弦/罗马数字/功能/近 4 小节/是否绕圈）· `last_bar`（上一小节织体/轮廓/结束音/旋律轮廓/发展手法）· `intensity_so_far` · `motif` · `recent_developments` · `director_note` · `user_prompt` |
| **决策预算（decision budget）** | 实时演奏时**决策时间由音频时钟封顶**——起播期等 `min(1.2×小节, [500ms, 8000ms])`，入队后按「队列音频还能撑多久」(`dryMs − 300ms`) 收紧。常量：`MIN_BUDGET_MS=500`、`MAX_BUDGET_MS=8000`、`BUDGET_MARGIN_MS=300`。**只用注入的 `now()`，不起新定时器** |
| **超预算 / deadlineMiss** | 预算先耗尽 → 该小节由 fixture 顶替并**如实标记** `deadlineMiss=true`，**下一小节仍重试真实渠道**（自愈）。**只有预算耗尽才走 fixture，真实答案先到必须用真实的** |
| **迟到小节顺延** | `_enqueueBar` 发现槽位已在过去时，把整小节连同 `_cursorSec` 锚点平移到 now——Web Audio 对排程在过去的乐音是**立即发声**，整小节会炸成一声 |
| **stripPrivate** | 发送前剥离 `_` 前缀字段（`_fixture` 权重不发给真实 API） |
| **后端链式降级** | worker 的 `/api/jev`：Workers AI 绑定 → `TYPESAFE_API_KEY` → `OPENROUTER_API_KEY`，逐个尝试；**AI 失败记忆**（isolate 内记住 5007，不再逐拍白撞） |
| **封闭转发** | `/api/llm` 只转发服务端 env 配置的端点，忽略请求体凭据——防开放中继（SSRF） |
| **限流** | 每 IP 计数，`RATE_LIMIT_PER_MIN` 默认 **90**/分钟（140 BPM 演奏需 ~35 次/分钟，30 没有余量）。isolate 内存计数，多实例下为尽力而为 |
| **确定性编辑** | 工作室的编辑操作（增/移/缩放/删/量化/力度/撤销）全是不调模型的纯函数 |
| **Jev 路由的修改** | 工作室里自然语言修改由 Jev 从封闭编辑命令集（加密/稀疏/移调/力度）中选择一个执行；离线渠道用关键词匹配 |
| **SMF Type-1** | 导出的 MIDI：tempo track + 左右手双轨，division=480；含 sustain CC64 换踏与分段 `set_tempo` |
| **回归门（gate）** | `npm run gate`：12 种子决策指标均值 + 相邻重复硬不变量，门槛单一真相源 `GATE_CONFIG`，CI 每次推送执行 |
| **部署后核验** | `scripts/verify-deploy.mjs`：拉线上的 js/api，断言刚改的代码片段真的在边缘上。**`npm test` 只证明磁盘上的代码对，不证明 CDN 边缘拿到的是这份** |

## 4. 界面域（可视化与通道纪律）

| 术语 | 定义 |
|---|---|
| **一维一通道** | 每个信息维度独占一种视觉通道：功能=**颜色** / 手法=**文字+形状** / 段落=**虚线+名字** / 手别=**填色** / 非和音=**亮边** |
| **不依赖颜色** | 任何标记都必须有独立于颜色的第二通道（形状或文字）——灰度/色觉障碍下仍可读。数据可视化的硬约束，非审美偏好 |
| **同源** | 图例（`LEGEND_ITEMS` / 行内 / 抽屉三处）、功能色（`FN_COLOR`）等必须来自**同一份数据**，有测试守着。**标记改了图例没改，比没图例更糟** |
| **归因可见化** | 内核只记归因字段、不做展示（"半成品仓库"模式）；前端轮统一兑现为界面标记 |
| **decisionGuards** | 把四类归因标记（断路/驳回/复读/超预算）收拢的纯函数，返回**描述符而非 HTML**，渲染层只拼装 |
| **张力对照带** | 演奏记录区顶部曲线：实线=**实际张力**、灰色虚线幽灵=**计划弧线**（`planTargetSeries`）。双遍时上一遍作灰色幽灵与当前遍**同轴叠加**（`chorusView` 折叠 x 轴为"遍内位置"） |
| **张力（barTension）** | 五分量加权：和弦音程不协和度（`shapeTension`）· 和声功能（`FUNCTION_TENSION`，属>下属>色彩>主）· 音域跨度 · 节奏密度 · 力度。**无音符 = 张力 0**（没有声音就没有张力） |
| **契合度 / 非和声音** | `barHarmonyFit` 给出该小节旋律的**和弦音占比**；非和弦音按 Kostka-Payne 分**经过音**（同向级进）/ **邻音**（折返级进）/ **倚音**（跳进后级进下行解决）。实测非和声音 **~37.6%**（**12 种子 1892 音**口径；样本量不同会在 ~38–40% 浮动，如 4 种子实测 39.5%）——古典语汇区间 20–40% |
| **动机卡** | 第 2 小节把主题旋律轮廓画成曲线（`motifShape`），并累计它**回来了几次** |
| **和声功能轨** | 和弦区下方横向色带，每小节一格按功能着色；断路器直接画在格上（顶部细刻线=循环锁死切刀，右端缺口=候选集驳回） |
| **张力带 / 卷帘 hover 读数** | 指针在通道上移动时的 crosshair + 文字读数（`hoverBarAt`）。**hover 只是增强，不是唯一通道**——张力数值另有常驻文本行与 aria |
| **氛围层 vs 信息层** | 判据：**「闭上眼睛少一半信息吗」**——舞台灯光闭眼后什么都不丢（纯氛围）；张力数值闭眼后丢了（必须留在文字通道） |
| **计费台账（ledger）** | `{tokens, usd, latencySum, latencyN}`——**tokens/费用/延迟的唯一记账口径**，两个界面共用。`accumulateLedger` 累加、`ledgerPills` 产出文案。**fixture 一律不计**（离线随机无网络请求、无费用，写进去是虚报）。轮次 50 修复：顶栏 pill 是两个视图共用的同一份 DOM，但计数器原先只住在实时界面——**工作室整条生成循环从不记账**，用户进工作室看到的是上一轮演奏的存量。**共用的显示 + 各写各的账 = 一半界面永远在说谎** |
| **兜底分因** | 两种兜底必须分开说：「渠道**坏了**」（429/断网/CORS/无 key，故障）vs「渠道**跟不上**」（`deadlineMiss`，设计在主动保住节奏）。toast 文案与状态栏后缀都不同（`·兜底` vs `·跟不上`），各自一次性告知、恢复即复位 |

## 5. 协作域（agent 的词汇）

| 术语 | 定义 |
|---|---|
| **AGENTS.md** | 项目宪法，所有 agent 第一站；含阅读地图、任务粒度与领地、收尾三件事、红线 |
| **MEMORY.md** | 项目记忆压缩索引，最新在最上。**完成任务不写记忆 = 未完成** |
| **docs/memory/** | 详细记忆；其 README 是索引，**建条目必须同时登记索引**（核对：`ls docs/memory/*.md \| grep -v README \| wc -l` 等于表内数据行数） |
| **接力条** | 任务未完成时留下的标准交接格式（目标/进度/下一步/已知坑/验收/领地） |
| **领地** | 一个任务涉及的文件清单；并行 agent 的领地**禁止交集** |
| **收尾三件事** | 完成任务必须：写 MEMORY.md 顶部条目 + 需要时建 `docs/memory/` 当日条目 + 契约变更时补 ADR |
| **ADR** | 架构决策记录：为什么这样设计、**被否决的方案是什么** |
| **红线** | 违反即回退的硬约束，见 AGENTS.md §5（禁框架/禁密钥入库/禁绕过候选集/禁删测试/禁提交 agent 本地状态/fixture 与真实同构/播放永不中断） |
| **死亡判据 / 免疫** | 「播放永不中断」需审计**全部死法**：决策失败、音频失败、**展示层异常**、迟到小节。`onBar` 是边境——进境的展示代码必须自负责（try/catch 隔离）。⚠️ **免疫会把病藏起来**：被吞的异常要能看到「发生了几次」，否则安全网变成遮挡布 |
