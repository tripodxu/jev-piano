# 2026-09-28 · 段落边界的和声与动机语义（迭代轮次 10 · 优化）

> 计划：[../superpowers/plans/2026-09-28-section-semantics.md](../superpowers/plans/2026-09-28-section-semantics.md)

## 起因

轮次 8 建的曲式只通过 `intensityTarget` 约束了**动态**——对**和声**和**动机**毫无影响。先量：

| 指标（12 种子 × 32 小节） | 改前 |
|---|---|
| 段落首拿到「承袭」 | 8/48 = **16.7%** |
| 全局「承袭」基线 | 12.2% |
| 段落首落在主和弦 | 11/48 = 22.9% |
| 段落末落在 V/I | 18/48 = 37.5% |

16.7% vs 12.2%，样本 48——**差异在噪声内，等于段落首和别处没什么两样**。A→A' 的再现关系在音乐上听不出来：两段只是并置，不是呼应。

## 音乐学依据

- **新段落从主和弦出发**：乐句可以从中途开始（半终止），但新段落是一次「重新立足」。
- **新段落重述主题**（承袭 `repeat`）：A→A' 的听觉关联正是靠「同一动机在新的和声语境里再出现一次」。没有这一步，两段只是并置。
- **段落收束比乐句收束更强**：乐句尾是半终止，段落尾是段落性收束。

## 做了什么

- `candidates.js` 新增 `developCandidates(plan, opts)`——把 composer 里内联的发展手法权重提成**纯函数**（顺带让 composer.js 瘦下来），并加段落语义：段落首 `repeat += 1.6` 且 `new *= 0.3`（新段落是「重述」不是「另起」）；段落末 `repeat += 0.8`、`inversion += 0.4`。
- `chordCandidates` 增加末尾 `opts` 参数：段落首主和弦 `+1.0`、段落末 V/I `+0.8`（**只做加法，不改既有项**）。
- `composer.js` 由 `sectionAt(plan.sections, this.index)` 算出 `sectionStart/sectionEnd`，同时喂给候选集与 `state`；`state.position` 增加 `section`/`is_section_start`/`is_section_end`，`state.form` 放整份曲式（`A:flat@1.2 B:rise@1.9 …`）——**模型需要看到全貌才谈得上呼应**，孤立告知当前段落 id 等于没告知。
- 测试 99 → **104**。

## 反思

- **我又一次从「榜单里没有」推断「不存在」。** 我看到「最常见的发展手法转移 top-6」里没有 `repeat`，就判断「承袭几乎从不触发」。下一轮测量直接推翻：**`repeat` 在 12/12 个种子全部触发**，占 12.2%。**把「没出现在榜单上」当成「不存在」——证据缺失不是证据。**
- **一个 2024 年的测试里藏着一个错的统计量。** `强度曲线：rise 弧线的强度随进度上升` 用的是**硬编码中心 1.5** 的协方差。段落化之后 `rise` 的实际均值是 1.67，中心选错会**直接抵消掉进度项**：真 Pearson 是 **0.1316**，而那个"协方差"只有 0.0455。**不是强度不升，是统计量错了。** 已改为真 Pearson 并加注释说明为什么中心必须取实际均值。
- **我为反向断言找错了基准。** 我先写「`flat` 弧线应无趋势（|r|<0.08）」，结果实测 **−0.352**——因为我自己第 8 轮的 `flat` 模板是 A1.4→B2.1→A'1.5→Coda1.0，整体就是缓缓下降的。**我对「flat」的理解和我的实现不一致。** 改成**相对比较**（`rise > flat + 0.3`）——真正要防的是「常数偏移让任何弧线都显得上升」。
- **我的临时诊断脚本本身也有 bug**：算跨种子相关时 `progress` 没有按种子重置，把「种子序号」也算进了进度。改用测试里的写法（每颗种子 0→0.969 各自重置）才得到正确的 −0.352。**测量工具出错时，测出的数字会非常有说服力。**
- **`chords` 降了 0.09 是预期的取舍**：更多段落首落在主和弦 = 和声更连贯，但词汇略收。结构性收益换一点点多样性，我认为划算——而且 `entropy` 反而升了 0.03。
