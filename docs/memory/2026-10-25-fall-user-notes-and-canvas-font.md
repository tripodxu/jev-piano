# 2026-10-25 · 跟弹音符进下落可视化 + canvas 字体回退修复（迭代轮次 56 · 前端）

## 做了什么

轮次 55 的两个余项一次结清：可玩性候选第一名（用户音符进 Fall）+ 轮次 54 记录在案的 canvas 字体 bug。

**领地**：`canvas.js`、`studio-roll.js`、`ui.js`、`main.js`、`styles.css` + `test/ui.test.mjs` + 文档。

1. **跟弹可视化（可玩性）**：演奏中用户点下琴键，该音以**紫色 + 近白描边**的块落在 Fall 的击键线上原地亮起——AI 的音符向下落，你的音符在原地亮起，两种来源一眼可辨。紫色独立于 AI 双手配色（琥珀/青绿），近白描边是颜色之外的**形状通道**（色弱可辨）。`Fall.push` 增加 `user` 旗标，绘制路径一处三元 + 一处条件描边。非演奏时点击不进 Fall（fall 未启动，回声行已有文字反馈）。
2. **canvas 字体回退修复（还债）**：轮次 54 记录了 `drawTimeline` 两处 `var(--mono)`；本轮全仓扫描又挖出**第三处**——`MotifCard` 的 `10px var(--sans, sans-serif)`（「动机」标签，无人发现因为回退到的默认字体碰巧不难看）。三处全部换成字面字体栈（与 styles.css 的 `--mono`/`--sans` 同族，注释指认同步关系）。**实际视觉影响**：工作室时间轴的段落名与「契合度」标签此前渲染成 Georgia 衬线体（上一处成功赋值的字体），现在按设计意图回到等宽。
3. **契约测试（轮次 53 方法论）**：新增「canvas `.font` 赋值禁止 CSS 变量」扫描测试——正则扫 `public/js/*.js` 全部 font 赋值，含 `var(` 即红。写进文档不如写进测试；这条规则从此有人盯着。
4. **图例同源**：`LEGEND_ITEMS` 新增「跟弹（下落音符）」组三条（你的音符/AI 右手/AI 左手）+ 三个 swatch 类；图例关键词断言同步扩展——「标记改了图例没改，比没图例更糟」第五次应验式防护。

## 坑（两个，都在测试上）

- **Proxy 记录的颜色断言带空格**：`Fall` 的颜色模板 `` `rgba(${base[0]},${base[1]},${base[2]},…)` `` 产出**无空格**的 `235,197,116`，我的断言写成 `235, 197, 116`——对着模板抄也要抄准分隔符。
- **图例关键词测试只扫 label+desc 不扫 group**：「跟弹」只出现在组名里，断言它必红。关键词应断言**标记名**（label），不是分组名。

## 设计取舍

- **用户音符不做下落动画**（只原地亮起）：它被点击的时刻就是发声时刻，`t=now` 是真相——硬给它造一段下落轨迹等于伪造「提前知道你要弹什么」。
- **`dur: 0.45`**：跟弹的即时反馈要能看清又不能久留——约半秒的余晖 + 命中光斑。
- 字体栈**字面复制**而非运行时读 CSS 变量：canvas.js 的「零 import」契约 + 逐帧读 computed style 违反能耗纪律；字面 + 注释指认 + 契约测试禁 `var(`，是这个约束下的诚实解。
