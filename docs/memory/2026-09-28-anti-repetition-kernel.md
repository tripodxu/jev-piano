# 反重复内核 + jevthoven 功能对齐 · 2026-09-28 08:12（commit 21c0270）

- **做了什么**：
  - **旋律指纹护栏**（初版）：onset+绝对音高指纹，与近两小节撞车时变形（整句移调/加经过音/倒影）。
  - **发展手法第 7 问**：承袭/模进/倒影/装饰/新句——第 2 小节节奏型与走向固化为动机，之后每小节在"统一"与"变化"间选择。
  - **节奏变奏与音区漂移**：每小节节奏位移/补弱位/删音；锚点中心随机游走 + 1/4 乐句换音区。
  - **jevthoven 功能对齐**：演奏指示（director_note，自然语言实时生效，下一小节起 Jev 遵守；离线渠道关键词近似）、暂停/继续（挂起 AudioContext 冻结时钟）、移调（12 调预选或计划自动决定）。
- **为什么**：动机统一与变化的平衡是"像作曲"与"像随机"的分水岭；director_note/暂停/移调是 jevthoven 实测好用的交互。
- **坑**：
  1. 暂停/恢复的时间基准必须只有一个来源（player 注入的 `now`）——AudioContext 挂起后恢复，调度自动对齐依赖这一点；多处读真实时钟必飘。
  2. 动机"固化"在第 2、3 小节采样后（`composer.motif`）——固化成过早（第 1 小节）动机本身没发展空间。
  3. 此版的指纹护栏是单次变形，被 13:51 的大修升级为迭代变形（见 anti-repetition-overhaul 条目）。
- **验证**：`npm test` 全绿；determinism 断言（同 seed 同输出）是 composer 测试的地基。
