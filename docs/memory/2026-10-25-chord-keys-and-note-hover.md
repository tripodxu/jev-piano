# 2026-10-25 · 和弦键亮起 + 卷帘悬停音符角色（迭代轮次 57 · 前端）

## 做了什么

轮次 55 留下的最后一个候选（`chordRole` 接卷帘 hover）+ 跟弹引导的补全：**和弦键亮起**。跟弹体验至此闭环——**亮键告诉你能弹什么，回声告诉你弹的是什么，下落可视化记住你弹过什么**。

**领地**：`ui.js`、`main.js`、`studio.js`、`studio-roll.js`、`styles.css` + 两份测试。

1. **和弦键亮起（可玩性）**：当前小节和弦里的琴键底部亮一道金线——跟着亮键弹就在和声里，跟弹从「试错」变「引导」。
   - `ui.js`：`keyMarks(low, high, pcs)`（音级类 → 键集合，null=熄灭）与 `markDiff(prev, next)`（最小 DOM 写入差集）两个纯函数 + `renderKeyboard` 新增 `mark(pcs)` 方法——**diff 更新**，和弦没换就零写入，换了也只动几个键（不是每小节重写 49 个）。
   - 实时页：`onBar` 亮当前和弦，`stopAll` 熄灭。工作室页：`syncKeyMarks()` 与 `chordCtx()` 同源——生成中逐小节亮、回放中挂在 `drawPlayhead` 的**换和弦分支**（30Hz 循环里只在和弦真的变化时才动）、停止回落到最后一小节、清空工作台熄灭。
   - 视觉：键底部 3px 金线用 `border-bottom`——**不用伪元素**，`.bk::after` 已被黑键前斜面占用（轮次 56 字体修复时学过的「一个伪元素只有一个用途」）。
2. **卷帘悬停音符角色（科学性）**：hover 到具体音符时，小节读数追加 `悬停 C5=根音` / `悬停 E4=大三度·外音`——与键盘回声同一内核（`chordRole`）。`hoverNote` 与 `hoverBar` 同一指针事件里更新，只在变化时重画。
3. **图例同源**：跟弹组补第 4 条「和弦键」（swatch 是一条金线），关键词断言同步。

## 设计取舍

- **`markDiff` 做成纯函数并测试**：能耗相关的不变量（「和弦没换就不碰 DOM」）值得一条断言，而不是只写在注释里——与轮次 51「静止画布不自我重绘」同一族契约。
- **和弦键挂在 `drawPlayhead` 的换和弦分支**而不是 30Hz 每帧：先读后写的同一条纪律——写 DOM 的频率由「数据变化」决定，不由「循环频率」决定。
- **金线只在键底部**而不是整键染色：整键染色会和「按下」状态（`.on` 的亮度/位移）打架，也吵；底部一道线是「路标」不是「路灯」。
