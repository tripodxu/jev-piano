# 反重复大修 · 2026-09-28 13:51（commit a085f4f）

- **做了什么**：`composer.js` +242 行重构反重复机制，`analyze-repetition.mjs` 新建（57 行量化工具），`composer.test.mjs` +49 行断言，README 补充指标表。六层机制全部落地：
  1. **旋律指纹护栏**：与最近两小节指纹（onset+绝对音高）撞车时，依次整句升/降一个音级→加经过音→倒影，直到避开**全部**已存指纹；变形后再检查，防"修东墙塌西墙"。
  2. **发展手法**（第 7 问）：承袭/模进/倒影/装饰/新句，以上一小节素材为原料。
  3. **左手织体逐小节变体**：每种织体带重击/呼吸空拍/方向翻转/色彩换位/经过音/音区抬升变体。
  4. **节奏变奏**：Jev 选"性格"，内核每小节位移/补弱位/删音/整体切分位移。
  5. **旋律跳进 + 时长人味**：20% 概率 ±6~12 半音真跳进；音符时长 ±15% 抖动。
  6. **音区漂移**：锚点中心随机游走 + 1/4 乐句整体换音区。
  和声层三件套：
  - **根音疲劳断路器**：每根音疲劳值随使用累计、随时间衰减（×0.93），超阈值（2.0）的根音从候选集剔除（含替换和弦）；三和弦循环最多 6 小节必被强制打断，迫使模型走 bIII/bVI/bVII/副属。
  - **候选集强制**：模型答案不在候选集内（含用标签作答、报被排除和弦）一律拒绝，回落最高权重候选——**非法着法不可表示**。
  - **替换和弦与乐句轮换**：副属/借用 iv/7sus4 悬挂/导七进入候选；乐句开头鼓励换进行起点；连续同和弦按池数放大罚分。
- **为什么**：修复前 32 小节曲目有可闻循环感——4 和弦循环、左手逐小节复读、旋律等长机械。目标：每次生成都像"这一首"，不像"这一首的循环"。
- **坑**：
  1. 指纹护栏的变形序列必须**迭代到避开全部已存指纹为止**，单次变形后不复查会把重复从小节 A 搬到小节 B。
  2. 真实 Jev 会"不守规矩"：用问题标签本身（`"chord"`）作为答案、或报一个刚被疲劳断路器排除的和弦来"表达意图"——**这是已实测的行为**，候选集强制不是防御性代码而是必需代码。
  3. 疲劳衰减系数（0.93）与阈值（2.0）是调出来的：衰减太慢则候选集被掏空、模型只能选垃圾；太快则断路器形同虚设。
- **验证**：`node scripts/analyze-repetition.mjs 32 <seed> random`（fixture，4 种子均值）——音程熵 2.2→2.4-2.8；跳进占比 4-9%→8-21%；左手唯一小节 15-18/32→26-28/32；和弦种类 6→8-10；相邻小节字面重复 偶发→0。真实 Jev 路径已冒烟（probe-bar）。
