## 三、三个静默缺陷（都已修）

三者共同特征：**画面还能看**，所以人工冒烟基本发现不了。

### 1. `canvas` 被归零层的 `max-width: 100%` 压扁（功能性回归）

```css
/* 轮次 72 新增的归零规则 */
img, canvas, svg { display: block; max-width: 100%; }
```

而卷帘的宽度是**数据**，不是布局：

```js
// studio-roll.js
const W = Math.max(720, beats * ZOOM + 4, idleW);   // ZOOM = 24 → 16 小节 = 1540px
canvas.style.width = `${W}px`;
```

`.rollwrap` 用 `overflow-x: auto` 承担滚动。`max-width:100%` 把 canvas 夹到容器宽后：

- 位图被**缩扁**（CSS 宽 < 位图宽）；
- 指针换算仍是 `px / ZOOM`（`pick` 在 `studio-roll.js`、`rollPos` 在文件尾部）→ **点、拖、双击删音全部落到错的小节**；
- 容器再也不滚（内容不再溢出）。

修法：

```css
img, svg { display: block; max-width: 100%; }
canvas { display: block; }   /* 宽度是数据，归零层不许碰 */
```

并加契约测试（`style-contract.test.mjs`）：扫描 `base.css`，任何选择器里出现 `canvas` 又写 `max-width` 即红。

### 2. `.stage` 只抄了配方的一半（视觉回归）

轮次 72 把「顶光内高光」从 `--elev-3` 里抽出来，变成独立的配方：

```css
--panel-shadow: var(--elev-3);
--panel-inset: var(--top-light);
```

`layout.css` 的 `.console, .programme, .stage` 用 `var(--panel-shadow), var(--panel-inset)`；
但 `stage.css`（后加载、同特异性）的 `.stage` 又写了一遍 `box-shadow: var(--elev-3)` —— 顶光就此消失。

**教训：跨层复用一套配方时，下游只能整份引用，不能挑其中一段。**
