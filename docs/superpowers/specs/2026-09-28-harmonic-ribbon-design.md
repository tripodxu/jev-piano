# 设计：和声功能轨 + 前端精修

- **状态**：已采纳并实现（2026-09-28，迭代轮次 3 · 前端）
- **skill**：`frontend-design`（审美方向）+ `impeccable`（`SCOPED_EXISTING_ALLOWED` → 精修不重做；收尾跑 `detect`）
- **自主性声明**：`impeccable` 的 `AUTONOMY_DIRECTIVE_CHECK` 要求先结构化提问一次；本 goal 是 256 轮自主迭代且已两次「继续」，提问会空转一轮，故**据 brief 推断方向并在此声明**：方向 = 全量打磨 + 轮换规则的前端位 = 精修，保留既有午夜音乐厅世界观。

---

## 1. 模式与方向

`impeccable` 的 mode 表：这个界面既是 **Operate**（用户完成演奏/编辑任务）也是 **Experience**（用户身处作品之中）。判定：**Operate 为主，Experience 为魂**。表达必须让位于扫读性，但这份作品值得被身处。

**保留**（incumbent 是权威）：午夜音乐厅、乌木钢琴、黄铜唯一强调色、猩红只属于琴毡、Cormorant Garamond + Noto Serif SC、`节目单`式决策日志、圆角制度（按钮胶囊 / 面板 12px）。

**不做**：重新定义视觉世界。`impeccable` 明确「Refinement preserves; redesign replaces」，本轮是 refinement。

## 2. 核心创意：和声功能轨（Harmonic Function Ribbon）

第 2 轮给内核加了一整层和声语义（T/S/D/Tp + 两条断路器 + 归因字段），**UI 零展示**。这违反项目自己的承诺「每个音符都能溯源到一条决策」——用户看不见功能层。

**方案**：在和弦区与下落音符之间加一条**横向功能轨**，每个已演奏小节一段，按功能着色，随演奏向右推进。

```text
┌──────────────────────────────────────────────────────┐
│ Am              第 12 小节 H4 · 强度 1.8              │
├──────────────────────────────────────────────────────┤
│ ▓▓▓▓▒▒▒▒▓▓▓▓████▓▓▓▒▒▒▒▓▓▓▓   ← 功能轨（T/S/D/Tp） │
│ 主    下属   属    主    色彩                        │
├──────────────────────────────────────────────────────┤
│              下落音符 canvas                          │
└──────────────────────────────────────────────────────┘
```

**为什么用 DOM 不用 canvas**：只有 ~16 段，DOM 免费给出 `aria`、焦点、hover 提示，且能用 CSS 变量统一配色；canvas 要自己补可访问性。项目已有一个 canvas（下落音符），不需要第二个。

**为什么值得做**：它是本项目独有的能力——别的音乐生成器给你音频，这里给你**和声轨迹**。一眼能看出 T-S-D-T 的进行、看出功能在哪一跳"拐弯"，也能看出断路器在哪儿切了一刀。

**配色**（在既有变量体系内新增，不引入新色相）：

| 功能 | 含义 | 取色 | 理由 |
|---|---|---|---|
| T 主 | 稳定归宿 | `--brass` 黄铜 | 唯一强调色留给"家" |
| S 下属 | 铺垫、向外打开 | `--lh` 青灰 | 冷色＝离开 |
| D 属 | 张力、拉回 | `--crimson` 猩红 | 琴毡色＝施力 |
| Tp 色彩 | 离调、借用 | 黄铜降饱和 | 不与前三者争 |

## 3. 断路器可见化

`decision.loopLocked` / `rejected` 两个归因字段同样零展示。功能轨上：
- `loopLocked` → 该段顶部一道细刻线（"这里被切断"）
- `rejected` → 段落右端一个小缺口（"模型越界被驳回"）
- 决策日志行内加一个功能徽章 + 断路器标记

这两者把 ADR-0003 的"剔除即强制"从代码里搬到了人眼前。

## 4. 精修项（`craft-floor` 的可执行清单）

| 项 | 现状 | 动作 |
|---|---|---|
| 文本选中 / 光标 | 浏览器默认，与世界无关 | `::selection` 用黄铜降饱和；`caret-color` 同族 |
| 滚动条 | 仅 `.dlog` 有，页面级缺失 | 全局 `scrollbar-color` / `-webkit-scrollbar` 乌木+黄铜 |
| 焦点环 | 有 `:focus-visible` 但被面板 `overflow:hidden` 裁切的风险 | 保留并统一 `outline-offset` |
| 空状态 | 决策日志空时一片空白 | 加节目单式空状态（"尚未开演——写下灵感后按下开始"） |
| 嵌套卡片 | `.plan-card` 嵌在 `.console` 面板里 | 降为「内嵌区域」：去掉独立边框阴影，用左侧黄铜细线 + 更紧的内边距 |
| 表格数字 | `.pill` 已有 `tabular-nums` | 决策日志的功能徽章与统计保持等宽数字 |
| 数字对比度 | `--text-faint: #8b8168` 在 `--ink-2` 上约 4.3:1 | 提到 ≥4.5:1 |

## 5. 不变量

- 元素 id 契约：`main.js` 按 id 取元素，新增 id 必须同时进 `index.html` 与 `main.js` 的 `els` 映射（AGENTS.md §2 高危区）。
- `prefers-reduced-motion` 下全部动效关闭。
- 零依赖：不引任何库（ADR-0004 红线一）；图标继续用内联 SVG。
- 移动端：功能轨在窄屏必须可横向滚动而非挤压。
