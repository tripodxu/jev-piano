## 1. 原型先行（动手前量）

第 4 轮的教训是「先量再改」。本轮先写了一次性原型 `scripts/tmp-tension.mjs` 验证算法站得住，三条证据：

**① 形状张力排序符合乐理直觉**

```
maj3 .12 < sus4 .20 < m/6/add9 .24 < 7 .28 < m6/7sus4 .36 < 9/m7 .40
      < aug/maj7 .44 < m9 .52 < maj9 .56 < dim .84 < m7b5 1.00
```

简单三和弦最平静，七和弦次之，减/半减最紧张——正是听感上的次序。

**② 它不是强度的换皮**

张力与 `bar.intensity` 的相关系数只有 **0.41 / 0.46**（两个种子）。如果接近 0.95，这个功能就只是把已有数字换个画法，没有新信息。

**③ 峰值落在正确的和弦上**

两个种子的张力峰值（0.69 / 0.71 / 0.77 / 0.78 / 0.79）**全部**出现在 `Dm7b5`（小调 iiØ）上——半减和弦是自然小调里最不协和的和弦，算法自己找到了它。

## 2. 创意核心

> **把"整首曲子演成什么样"画出来，并且和"原本打算演成什么样"叠在一起看。**

第 1 轮起，项目一直在强调「每个音符可溯源到一条决策」——但那是**单个小节**级别的。本轮把可溯源推到**整曲级别**：一条随演奏生长的张力曲线，外加计划弧线作为幽灵虚线。

```text
张力 1.0 ┤        ╭─╮                    ╭╮
          │  ╭────╯ ╰──╮        ╭──╮   ╭╯╰─╮
      0.5 ┤─╯ ·········╰──╮ ···╭╯ ·╰───╯ ··╰─╮
          │   ╭───╮  ╭────╰─╮╭──╯            ╰──
      0.0 ┼───┬───┬───┬───┬───┬───┬───┬───┬──
            A1  A2  A3  A4（乐句分隔）
              实线=实际张力   虚线=计划弧线
```

**为什么这个项目独有**：别的 AI 音乐生成器给你音频。这里给你**和声轨迹**——你能看着 Jev 一小节一小节地把曲子的形状走出来，也能看出它在哪儿偏离了自己的计划。

## 3. 方案对比（批准门替代物）

| 方案 | 内容 | 取舍 | 结论 |
|---|---|---|---|
| **A. 只显示实际张力** | 一条曲线 | 简单；但没有参照系，看不出"偏离计划"这件最有价值的事 | ✗ |
| **B. 实际 + 计划弧线对照**（采纳） | 两条线 | 多一条虚线；换来"模型 vs 意图"的直接可读性 | ✓ |
| **C. 把张力喂回决策器**（张力问 / 按张力调强度） | 闭环控制 | 听起来更美，但会动到第 1-2 轮刚稳住的决策内核，指标要全部重跑；且张力与 intensity 本身相关 0.45，闭环容易自激 | ✗（另开任务） |
| **D. 纯文本/数字展示** | 表格列出每小节张力 | 不必 canvas；但 32 个数字不构成"形状"，失去这个功能的意义 | ✗ |

**本轮只做 B，不做 C。** 理由：C 会同时改动候选与决策，正是第 2 轮花了一整轮才稳住的部分；而张力与 intensity 相关 0.45，把它接进反馈环有自激风险。先让它**可见**，用眼睛判断它是否有决策价值，再决定要不要闭环——这比先接线再回滚便宜得多。

## 4. 算法

五个分量加权求和，归一到 0..1：

| 分量 | 来源 | 权重 | 含义 |
|---|---|---|---|
| 和声 | `CHORD_SHAPES` 各音程的不协和度求和 ÷ 1.25 | 0.34 | 和弦本身有多刺耳 |
| 功能 | T .15 / S .45 / D .85 / Tp .55 | 0.24 | 离"家"有多远 |
| 音域 | `(max−min midi)/48` | 0.16 | 声音摊得多开 |
| 密度 | `min(1, 右手音数/8)` | 0.12 | 织体多满 |
| 动态 | `intensity/3` | 0.14 | 力度 |

音程不协和度表 `DISS`（Plomp-Levelt 思想的简化版）：半音(1) .8、全音(2) .15、小三(3) .25、大三(4) .1、纯四(5) .2、三全音(6) .8、纯五(7) .05、小六(8) .45、大六(9) .15、小七(10) .2、大七(11) .4。

## 5. 模块与不变量

- 新建 `public/js/tension.js`（纯函数，无 DOM）：`shapeTension`、`barTension`、`tensionSeries`、`targetSeries`。
  **为什么不塞进 `music.js`**：那是乐理内核（音阶/和弦/声位），张力是**对已生成音乐的分析**，职责不同、可独立测试。
- `ui.js` 新增 `TensionGraph` 类，沿用既有 `Fall` 类的构造/启动/停止模式（canvas + ResizeObserver + setInterval 而非 rAF，理由同 `Fall`：标签页被遮挡时 rAF 会被暂停）。
- **不改任何决策逻辑**——纯展示层，指标不可能退化。
- 元素 id 契约：新增 `#tensionCanvas` 必须同时进 `index.html` 与 `main.js` 的 `els`。
