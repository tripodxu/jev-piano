# 动机地图 Implementation Plan

> **执行方式**：本会话内联执行（用户明确要求不使用子代理）。
> **skill**：`impeccable/delight`（「这个瞬间必须只有这个产品做得出」是本轮的取舍判据）

**Goal**：让第 11 轮真正工作的**动机发展**在界面上可见——用户能看见曲子的主题长什么样，以及它在哪些小节回来了。

**Delight thesis**：*「你的主题在曲子里回来了」*。这是 AI 音乐生成器普遍给不了的东西（它们给音频，不给可溯源的结构），而本项目第 11 轮才让它真的成立。处理方式必须**由产品机制与既有世界观推导**，不用通用动效清单。

## 设计

### ① 动机卡（Motif card）
一首曲子有一个「形状」——第 2 小节旋律的音高轮廓。用一小块 canvas 把它画出来，像曲子的指纹。动机诞生（第 2 小节）时出现，此后常驻。

### ② 功能轨上的发展手法通道
每段已有和声功能着色（T/S/D/Tp）。现在加第二行**发展手法**标记：

| 手法 | 标记 | 含义 |
|---|---|---|
| 承袭 repeat | **闭合括线 + 亮边** | 「主题又回来了」 |
| 模进/倒影/装饰 | 细字（模/倒/装） | 对刚才那句的变形 |
| 新句 new | 无标记 | 全新材料 |

**不依赖颜色**：承袭用**形状**（括线）+ 文字「承」，其余用文字缩写。颜色仍归功能，形态归手法——两个维度用两套通道，互不干扰。

### ③ 首次再现的高亮
第一次「承袭」发生时，动机卡短暂强调一次。**有节制**：`delight` 明确「不要为普通点击制造庆祝」；而主题第一次回来是这个产品里真正有意义的瞬间，一次静默强调是赚来的。**只此一次**，之后不重复——重复一百次还讨喜是它的判据。

```js
/** 发展手法的短标签——功能轨上的文字通道（与颜色无关，灰度/色觉障碍下同样可读） */
export const DEVELOP_ZH = { repeat: '承', sequence: '模', inversion: '倒', ornament: '装', new: '' };

/** 音高序列 → 归一化轮廓 [{x,y}]，x/y 都在 0..1。整体移调不改变形状（同一动机换个八度仍是同一形状）。 */
export function motifShape(midis) {
  if (!Array.isArray(midis) || !midis.length) return [];
  const lo = Math.min(...midis), hi = Math.max(...midis);
  const span = hi - lo || 1;
  const n = midis.length;
  return midis.map((m, i) => ({ x: n > 1 ? i / (n - 1) : 0, y: n > 1 ? 1 - (m - lo) / span : 0.5 }));
}
```

- [ ] **Step 4: 运行确认通过**
